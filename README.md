# Halloween Game Tools - Windows beta

Portable desktop utility with possible-exit maps, bright exit symbols, a crosshair, keyboard/mouse macros, experimental map-name recognition, and experimental player-arrow glow.

## Download and run

Download the ZIP from [Releases](https://github.com/googoogaagaa23/halloween-game-tools-download/releases), extract the whole folder, then open **Halloween Game Tools Test.exe** on Windows 10/11. Codex and an installer are not required. Keep the included files together.

- Hold **Tab** or Xbox **View / Select** to show the map overlay; release to hide it.
- **Ctrl+Alt+G** opens settings. Adjust the overlay size/alignment for your display.
- Hold Tab and right-click to cycle exit maps manually.
- Player glow looks for a black arrow with a pale outline. If several match, point at yours and tap middle mouse while the map is open.
- Macro starts paused: Mouse 4 starts/pauses, F3 switches output, F9 stops. Controller support opens the map overlay; macros produce keyboard/mouse input.

Recognition is a beta feature tested with reference map names, generated arrow scenes, and a supplied real player-marker screenshot. Version 1.1.2 fixes thin gray/ivory arrow outlines; the real reference passes at four quarter-turn rotations and three image scales. Detection accuracy, display compatibility, and controller behavior still need verification in actual Halloween gameplay. Similar icons can produce missed or incorrect matches; the feature can be turned off. This app does not read game memory or modify game files. Captured images stay in memory.

The ZIP has fresh settings and contains no creator's personal app state or logs. The app is unofficial. Possible-exit map images are by **DeftyConch**; creator attribution and source links are included in RESEARCH.md and preserved on the images. Possible locations are not a guarantee of active exits in a round.
